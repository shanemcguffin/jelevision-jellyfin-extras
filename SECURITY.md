# Security

Please report vulnerabilities privately through GitHub's security advisory
feature.

The plugin needs no access token for either public metadata source. It should
not transmit library identifiers or local media information. A custom catalog
URL is trusted configuration and should point to a service controlled by the
server owner.

Reports can contain local library titles and item identifiers. Treat the
Jellyfin plugin configuration directory as private server data and do not
attach raw reports to public issues without redacting them.
